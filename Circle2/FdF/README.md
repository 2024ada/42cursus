# FdF

**높이 데이터를 3D 와이어프레임으로 탐색하는 그래픽 뷰어**

## 무엇을 만들었는가

텍스트 파일의 높이 값을 3차원 좌표로 해석하고, 인접한 점들을 선으로 연결해 지형을 보여주는 프로그램입니다. 렌더링에 더해 키보드·마우스 조작, 메뉴, 글꼴, 저장 확인 팝업을 구성했습니다.

**사용 기술:** C, MiniLibX, X11·Xext, 수학 라이브러리, 직접 구현한 Libft·ft_printf·get_next_line.

## 과제에서 요구한 범위

[Subject v3.2](en.subject.pdf)의 필수 과제는 높이 지도를 등각 투영으로 그리는 것입니다.

| 구분 | 명세의 요구사항 |
| :--- | :--- |
| 필수 | `.fdf` 지도 읽기, MiniLibX 이미지로 등각 와이어프레임 표시, 창·종료 처리 |
| 보너스 | 추가 투영 하나, 확대·축소, 이동, 회전, 자유롭게 정하는 추가 기능 하나 |

직교 투영과 확대·이동·회전은 지정된 보너스입니다. 자유 추가 항목은 메뉴·글꼴·화면 저장으로 구성하고, 지도를 처음 열었을 때의 배치와 초기화 동작도 넣었습니다.

## 좌표가 화면에 나타나는 과정

```mermaid
flowchart LR
    A["높이·색상 텍스트"] --> B["중심을 맞춘 3D 좌표"]
    B --> C["스케일·XYZ 회전"]
    C --> D["등각 또는 직교 투영"]
    D --> E["화면 위치로 이동"]
    E --> F["인접 점을 선으로 연결"]
    F --> G["GUI와 합성해 표시"]
```

### 좌표 변환을 단계별로 구성

[`fdf_transform.c`](mandatory/fdf_transform.c)는 스케일과 각 축의 회전, 평행 이동을 별도 함수로 구현합니다. [`fdf_isometric.c`](mandatory/fdf_isometric.c)는 이를 순서대로 적용하고, 등각 투영에서는 다음 식을 사용합니다.

```text
screen_x = (x - y) × cos(30°)
screen_y = (x + y) × sin(30°) - z
```

[`fdf_view.c`](mandatory/fdf_view.c)는 투영된 지도 범위를 구해 초기 배율과 화면 중앙 위치를 계산합니다. 크기나 높이 범위가 다른 지도도 초기 화면에 맞춰 배치하도록 구성했습니다.

### 정수 오차 누적으로 선을 그리기

[`fdf_line.c`](mandatory/fdf_line.c)는 Bresenham 방식으로 정수 좌표와 오차 누적을 사용해 픽셀을 결정합니다. 지도 각 점에서 오른쪽·아래쪽 이웃으로 선을 연결하고, 지도 표시 영역 안에 픽셀을 기록합니다.

### 그래픽 라이브러리 위에 GUI를 구성

[이미지 처리](mandatory/fdf_image.c)와 [XPM 팔레트 해석](mandatory/fdf_palette.c)으로 픽셀 버퍼에 UI를 합성합니다. 내장된 **95개 글리프와 59개 위젯**을 사용하고, [글꼴 처리](mandatory/fdf_font.c)는 전경·배경 색에 맞게 글리프 팔레트를 조정합니다.

[이벤트 처리](mandatory/fdf_event.c)와 [메뉴](mandatory/fdf_menu.c), [팝업](mandatory/fdf_popup.c)을 나누어 조작과 표시를 연결했습니다.

### 파일 형식까지 직접 구성하는 화면 저장

[`fdf_save.c`](mandatory/fdf_save.c)는 PPM 헤더와 RGB 바이트를 기록합니다. GUI를 포함한 전체 창 대신 지도 표시 영역을 저장하고, [파일명 생성](mandatory/fdf_output.c)은 지도 이름에 캡처 번호를 붙입니다.

## 빌드와 실행

Linux에서 C 컴파일러, `make`, X11·Xext 개발 라이브러리와 그래픽 디스플레이 환경이 필요합니다. MiniLibX 소스는 저장소에 포함되어 있습니다.

```sh
make
./fdf maps/default/42.fdf
```

`make bonus`도 `fdf` 실행 파일을 만듭니다. 현재 기본·보너스 디렉터리는 파일명과 헤더명 차이를 제외하면 같은 기능을 포함합니다.

`make clean`, `make fclean`, `make re`를 지원합니다.

## 조작

| 입력 | 동작 |
| :--- | :--- |
| `I` / `O` | 등각 / 직교 투영 |
| `+` / `-` | 확대 / 축소 |
| 방향키 | 위·아래·왼쪽·오른쪽 이동 |
| `W` / `S` | X축 회전 |
| `A` / `D` | Y축 회전 |
| `Q` / `E` | Z축 회전 |
| `R` | 현재 투영의 초기 뷰로 복원 |
| `P` | 화면 저장 확인 팝업 |
| `Esc` | 종료 |

사이드 메뉴에서도 이동·투영·확대·회전·저장 기능을 선택할 수 있습니다. 회전 메뉴는 왼쪽·오른쪽 마우스 버튼으로 방향을 나눕니다.

## 입력과 파일 구조

높이 값은 공백으로 구분하며, 색상은 `높이,0xRRGGBB` 형태로 지정합니다.

```text
0  1,0xFF6600  0
1  3,0x00BABC  1
0  1           0
```

| 경로 | 내용 |
| :--- | :--- |
| [`mandatory/`](mandatory/) | 파싱, 좌표 변환, 렌더링, UI |
| [`bonus/`](bonus/) | 보너스 빌드용 소스 |
| [`maps/default/`](maps/default/) | 실행에 사용할 지도 |
| [`maps/extra/`](maps/extra/) | 크기·행 길이·숫자 범위 등 경계 입력 파일 |
| [`minilibx-linux/`](minilibx-linux/) | 외부 그래픽 라이브러리 |
| `libft/` · `ft_printf/` · `get_next_line/` | 재사용하는 직접 구현 라이브러리 |

`maps/extra`의 파일은 경계 입력을 살펴보기 위한 자료입니다. 자동 테스트 통과 결과를 의미하지는 않습니다.
