## 무엇을 만들었는가

`printf`의 주요 변환자와 출력 옵션을 구현한 C 정적 라이브러리입니다. 형식 문자열을 해석하고, 인자의 자료형에 맞게 값을 변환한 뒤 정렬·패딩·접두사를 적용해 출력합니다.

**사용 기술:** C, `stdarg.h`, `va_list`, `write`, 직접 구현한 [Libft](../../Circle0/Libft/README.md), Makefile.

## 과제에서 요구한 범위

[Subject v10](en.subject.pdf)은 `%c`·`%s`·`%p`·`%d`·`%i`·`%u`·`%x`·`%X`·`%%`를 필수로 지정합니다. 보너스는 최소 출력 폭, `.정밀도`, `-`·`0` 조합과 `#`·`+`·공백 플래그입니다.

이 프로젝트는 해당 출력 범위를 구현합니다. 형식 해석과 출력을 나누고, 플래그의 우선순위와 부호·접두사 길이를 함께 계산하도록 구성했습니다.

## 지원하는 출력

| 구분 | 지원 범위 |
| :--- | :--- |
| 문자·문자열 | `%c`, `%s` |
| 정수 | `%d`, `%i`, `%u` |
| 16진수·주소 | `%x`, `%X`, `%p` |
| 기호 | `%%` |
| 플래그 | `-`, `0`, `#`, `+`, 공백 |
| 필드 크기 | 숫자로 지정하는 출력 폭과 `.정밀도` |

## 구현에서 주목할 부분

### 형식 해석과 자료형별 출력을 분리

[`ft_printf.c`](ft_printf.c)는 일반 문자와 변환 구문을 구분하며 `va_list`를 전달합니다. [`ft_printf_utils.c`](ft_printf_utils.c)는 변환자별 출력 함수를 선택하고, 정수·문자열·주소 등의 세부 변환은 각각의 파일에서 처리합니다.

### 하나의 플래그 구조체로 출력 조건 관리

[`ft_printf_bonus.c`](ft_printf_bonus.c)는 `t_flag`에 정렬 방향, 부호, 패딩, 접두사, 출력 폭, 정밀도를 저장합니다. [`ft_printf_utils_bonus.c`](ft_printf_utils_bonus.c)는 `-` 또는 정밀도가 지정되었을 때 `0` 패딩을 해제하는 등 옵션 간 관계를 조정합니다.

### 부호·접두사와 숫자 길이를 함께 계산

[정수 출력](ft_printf_d.c), [16진수 출력](ft_printf_x.c), [주소 출력](ft_printf_p.c)은 값의 자릿수와 추가 기호를 고려해 출력 문자열을 구성합니다. 문자열의 경우 [정밀도에 따른 길이 제한과 NULL 처리](ft_printf_s.c)를 별도로 다룹니다.

## 빌드와 사용

```sh
make
# libftprintf.a 생성
```

현재 Makefile은 기본 빌드에 플래그 관련 소스도 포함합니다. `make bonus`는 같은 라이브러리를 생성합니다.

사용 예시:

```c
#include "ft_printf.h"

int main(void)
{
    ft_printf("number=%d hex=%#x\n", 42, 42);
    ft_printf("|%10s| |%.3s|\n", "hello", "world");
    return (0);
}
```

위 예시를 `demo.c`로 저장한 경우:

```sh
cc -Wall -Wextra -Werror demo.c -L. -lftprintf -o demo
./demo
```

`make clean`, `make fclean`, `make re`를 지원합니다.

## 구현 범위

위 표에 해당하는 변환과 옵션을 대상으로 합니다. 부동소수점 변환, 길이 지정자, `*`를 이용한 동적 출력 폭·정밀도는 구현 대상에 포함되어 있지 않습니다.
